# NDB Evidence-Gated Roadmap

These are proposed work packages, not claims of completion. Actual sequencing is subject to the Architect's decisions.

| Stage | Goal | Evidence required to advance |
| --- | --- | --- |
| 1. Identity | Maintain authoritative chain and contract references | Source verification links, current block-anchored observations and independent cross-checks |
| 2. Contract assessment | Understand supply, transfer behavior and authority | Reproducible source review, tests and independently qualified security assessment |
| 3. Transparency | Explain distribution, liquidity and risks | Dated, reproducible methodology and independently verifiable sources |
| 4. Agent use cases | Prototype useful service workflows | Offline or testnet evidence; bounded permissions; independent QA; no real-value spending |
| 5. Production readiness | Assess whether a limited authorized pilot is appropriate | Security and legal review, incident and reconciliation plans, explicit owner approval and documented operational controls |

Future speed, price, liquidity, partnerships, listings and adoption must be supported by dated external evidence before publication. No investment return or launch date is promised by this roadmap.
