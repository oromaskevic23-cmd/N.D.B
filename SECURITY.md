# Security Policy

Please do not post private keys, seed phrases, credentials, exploit details or sensitive logs in a public issue. Use GitHub private vulnerability reporting if enabled; otherwise ask the repository owner for a secure reporting channel without disclosing the details publicly.

The included observation tool is read-only and does not sign or broadcast transactions. Keep signing credentials outside agent prompts, this repository and logs. Validate all proposed on-chain or off-chain integrations separately.

The Sourcify source-match record is not an independent security audit. An audit, incident response process and production security controls require separate evidence.
