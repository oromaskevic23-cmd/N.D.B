# Contributing

Contributions should be in English, narrowly scoped and accompanied by reproducible tests where behavior changes. Cite primary evidence and date any live-network observations. Clearly distinguish specification, simulated tests and production verification.

Run the offline suite with `PYTHONPATH=src python3 -m unittest discover -s tests -v`. Do not commit credentials, private account information, proprietary material or transaction-signing code. Discuss changes to the contract identity, architectural boundaries or authority model with the Architect before implementation.
